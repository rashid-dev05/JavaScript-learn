# MANDATORY 6-STAGE AUDIT PROTOCOL (Apply to every code submission)

### 1. Syntax, Type Coercion & Logic Audit
- Enforce strict equality (`===` / `!==`) and block-scoped declarations (`const`, `let`); eliminate `var`.
- Catch falsy-value traps (`undefined`, `null`, `NaN`, `0`, `""`) and apply Optional Chaining (`?.`) and Nullish Coalescing (`??`) where appropriate.
- Fix Scope, Hoisting, Closure, and lost `this` context bugs (especially inside callbacks and event listeners).
- Eliminate infinite loops, off-by-one boundary errors, and unintended object/array mutations.

### 2. Async, Promises & Network Resilience
- Detect all unhandled `async/await` and `Promise` chains (`UnhandledPromiseRejection`) and wrap them in structured `try / catch / finally` blocks.
- In `fetch` calls, validate HTTP status codes (`if (!response.ok)`) in addition to catching network failures.
- Prevent **Race Conditions** on concurrent requests using `AbortController` or request versioning.
- Optimize independent sequential async operations with `Promise.all` or `Promise.allSettled`.

### 3. DOM Null-Safety, Lifecycle Timing & Memory Leaks
- **Zero `Cannot set properties of null` Errors:** Never write to `.innerHTML`, `.textContent`, or `.style` without verifying that the target DOM element exists (`if (!el) { console.error(...); return; }`) and that the script executes after the DOM is ready (`DOMContentLoaded` or `defer`). Flag mismatched HTML/JS selectors or stale Service Worker cache desyncs.
- **Storage & PWA Resilience:** Wrap all `localStorage` / `sessionStorage` access in `try / catch` blocks so browser Tracking Prevention or private mode blocks never crash execution. Flag third-party CDN dependencies that may fail offline or trigger storage blocks.
- **Memory Leak Prevention:** Clean up duplicate `addEventListener`, `setInterval`, `setTimeout`, and `requestAnimationFrame` handlers; prefer **Event Delegation** for dynamic lists and minimize layout thrashing (reflow/repaint).

### 4. Security & Sandbox Isolation Audit
- **Iframe Sandbox Escape Prevention:** NEVER allow `allow-scripts` and `allow-same-origin` together on the same `<iframe>` `sandbox` attribute (which lets embedded code access `window.parent` and strip its own sandbox). Enforce strict isolation (`sandbox="allow-scripts"`) using `srcdoc` or `postMessage`.
- **XSS & Injection Defense:** Forbid inserting untrusted data via `innerHTML`; use `textContent`, `createElement`, or strict sanitization. Eliminate `eval()`, `new Function()`, ReDoS-vulnerable regexes, and Prototype Pollution vectors.
- Validate all function inputs defensively at entry points.

### 5. Edge Cases Coverage
Verify the code never crashes when:
- Empty arrays (`[]`), empty objects (`{}`), `null`, or `undefined` are passed;
- Unexpected data types arrive (e.g., strings instead of numbers);
- Network drops offline or browser storage is restricted;
- Users trigger rapid repeated clicks/inputs (apply `debounce` / `throttle` where needed).

### 6. Performance & Clean Architecture
- Reduce unnecessary nested loops ($O(n^2)$) to $O(n)$ using `Map` or `Set`.
- Refactor duplicated or monolithic logic into clean, single-responsibility functions.
